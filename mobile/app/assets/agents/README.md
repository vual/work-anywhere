# Agent icons

`codex.svg` and `claude-code.svg` are the color variants `codex-color.svg` and
`claudecode-color.svg` from [LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg@1.102.0`, MIT License). The only local changes are
fixed 24×24 dimensions instead of `1em`, removal of the inline `style`, and a
stable gradient id, so `flutter_svg` can parse them. The product names and marks
belong to their respective owners.
